The project covers data synchronization, configuration setup, model training, visualization of training metrics, and prediction on new images.

## Project Overview
This notebook provides an end-to-end workflow for training a custom YOLOv8 object detection model. The primary goal is to accurately detect and classify different Indian and Latin script types within images. The process includes:
- Synchronizing dataset from Google Drive to Colab environment.
- Generating a YOLO-compatible YAML configuration file.
- Training a `YOLOv8s` model with custom parameters tailored for text detection.
- Loading and visualizing training performance metrics (loss curves, mAP).
- Running inference on a sample image and displaying the results.

## Dataset
The model is trained on a custom dataset, referred to as `DLCV_split`, which contains images and corresponding YOLO-format bounding box annotations for various text scripts. The dataset is expected to be stored in Google Drive and synced to the Colab runtime.

## Model
The project utilizes the `ultralytics` YOLOv8 framework, specifically the `yolov8s.pt` (YOLOv8 small) pre-trained model, which is then fine-tuned on the custom script detection dataset. Key training parameters include:
- **Epochs**: 50
- **Image Size**: 640x640 pixels
- **Batch Size**: 16
- **Augmentations**: Critical for text, `fliplr=0.0` (no horizontal flip), `flipud=0.0` (no vertical flip), `degrees=2.0` (slight rotation).

## Usage
Follow the cells sequentially in the Colab notebook:
1.  **Sync Data**: Mount Google Drive and synchronize your dataset.
2.  **List Data**: Verify the dataset contents.
3.  **Write YAML Config**: Create `script_data.yaml` defining dataset paths and class names.
4.  **Train Model**: Execute the training script using `model.train()`.
5.  **Load Results CSV**: Load the `results.csv` generated by YOLOv8 for analysis.
6.  **Plot Training Metrics**: Visualize loss curves and mAP over epochs.
7.  **Predict Image**: Run inference on a test image and display predictions.

## Training Metrics Visualization
The notebook generates plots for:
- **Box Loss**: Training and validation bounding box loss.
- **Class Loss**: Training and validation classification loss.
- **DFL Loss**: Training and validation Distribution Focal Loss.
- **mAP50**: Mean Average Precision at IoU=0.50 for validation.
- **mAP50-95**: Mean Average Precision across various IoU thresholds (0.50 to 0.95) for validation.

These plots provide insights into the model's learning process and performance over 50 epochs.
